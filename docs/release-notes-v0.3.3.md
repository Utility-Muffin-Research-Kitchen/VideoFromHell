# Video From Hell 0.3.3

Video From Hell is an optional video player for Leaf on the Miniloong Pocket 1.
Install or update it through Pak Rat.

## Changes since 0.3.2

- Play smoothly. The picture froze for a moment every three seconds and skipped
  a few frames, while the sound kept going. It now shows every frame at the
  video's own frame rate.
- Keep quick button presses. Pressing a direction several times in a row could
  drop all but the first press.

Thanks to kirbstersMS and The Talking Yogurt for reporting the choppy playback
and sending a log.

The update keeps your videos, watch history and queue. Video From Hell remains
optional and is not included in Leaf SD release ZIPs.
